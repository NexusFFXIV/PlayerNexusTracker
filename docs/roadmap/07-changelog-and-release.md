# Stufe 7 — Changelog und Release-Transparenz

## Arbeitspakete

- Changelog-/About-Bereich im Plugin.
- Installierte Version, Release-Version, Schema-Version und wichtige Änderungen
  anzeigen.
- Version, Manifest und Assembly weiterhin in CI abgleichen.
- Fehlende Changelog-Version als CI-Fehler behandeln.
- Run-Log und Changelog klar trennen.
- Changelog-Texte lokalisierbar machen.

## Akzeptanz

Jede veröffentlichte Version besitzt einen sichtbaren Changelog-Eintrag und
konsistente Versionsinformationen.
